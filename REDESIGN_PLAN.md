# Courtside Redesign Plan

## Executive Summary
Strip back overdesigned elements to achieve Stripe-level design quality through restraint, consistency, and systematic thinking.

## Implementation Phases

### PHASE 1: Foundation (Typography + Color System) ✓
- Establish 3-weight type scale
- Consolidate to single blue accent
- Remove unnecessary color variables

### PHASE 2: Branding Cleanup
- Replace emoji logo with clean wordmark
- Remove tagline
- Simplify logo styling

### PHASE 3: Component Simplification
- Strip game cards of 8 visual effects down to 2
- Simplify navigation
- Clean up date picker

### PHASE 4: Microcopy & Spacing
- Remove redundant labels
- Implement 4px spacing system

### PHASE 5: Surface Treatment
- Reduce glass effects
- Flatten card surfaces

### PHASE 6: Polish & Refinement
- Fix button styles
- Final cleanup

## Testing Checkpoints
- After Phase 1: Color consistency
- After Phase 2: Professional branding
- After Phase 3: Visual weight reduction
- After Phase 6: Full comparison screenshot
